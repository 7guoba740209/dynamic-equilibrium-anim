物理量关系解析：量的链条与内在逻辑

本实验要处理的物理量共 8 个：遮光片宽 d、挡光时间 Δt、两门间距 Δx、质量 m、速度 v、动量 p、动能 Ek、恢复系数 e。 它们被两条链子串起来——测量链（由几何量和时间量得到速度）与守恒链（由质量与速度得到动量）。
核心技术点 双门法 + 匀减速外推修正　双门法 v̄ = Δx/Δt 测得的其实是两门之间那段路程的平均速度， 而守恒式要的是碰撞瞬间的速度。若气垫存在残余摩擦减速，两者相差可达 15%。 物理上正确的修正：设减速度 a = μg，区间中点时刻为 tmid，则 v(tref) = v̄ + a(tmid − tref)，其中 tref 为碰撞时刻。 本系统已内置该修正，实测还原精度达 0.001%（数值验证：μ 从 0 到 0.02 全程误差 < 0.001%）。
不做修正时，摩擦越大守恒结论越不可靠（μ=0.02 时误差达 28%）；做了修正则始终 < 0.001%。
真实限制 以下情形物理上无法测速，不是软件缺陷，实验室同样会遇到：
① 等质量弹性碰撞时 v1′ = 0，滑块停住，不再通过任何光电门；
② 轻物反弹速度过小时，滑块在两门之间停下；
③ 完全非弹性碰撞后两滑块黏成 0.18 m 长的整体，两端通过两道门的时刻相差可达 0.45 s（此时须按整体理解测速区间）。

关系一：碰撞后速度随质量比 r = m2/m1 的变化（弹性）

斜率 1 与 −1 的两条直线交于 r = 1。等质量时 v1′ = 0、v2′ = v10，即"交换速度"。r > 1 时入射物反弹，r < 1 时两物同向。

关系二：动能损失随恢复系数 e 的变化

ΔEk = ½μ(1 − e²)(v1 − v2)²，与 e² 成正比。e = 1 损失为零（弹性），e = 0 损失最大（完全非弹性）。

关系推导：从动量守恒到速度通解

前提 系统水平方向合外力为零：ΣFx合 = 0
气垫导轨的工作原理：压缩空气经滑块底部小孔喷出，在滑块与导轨间形成约 1 mm 厚的气垫，使滑块与导轨的接触变为气—气摩擦。 正常工作时摩擦因数仅 10⁻³ ~ 10⁻² 量级，故 μmg ≪ 系统动量，摩擦冲量可忽略；同时导轨水平放置消除了重力沿程分量。
守恒式 m1v1 + m2v2 = m1v1′ + m2v2′ —— ① 动量守恒
补充 恢复系数定义：e = (v2′ − v1′) / (v1 − v2)
联立 两式联立消去 v1′、v2′，得碰撞后速度通解：
v1′ = [(m1 − em2)v1 + (1 + e)m2v2] / (m1 + m2)
v2′ = [(1 + e)m1v1 + (m2 − em1)v2] / (m1 + m2)
为什么必须补一个方程？　动量守恒只给出一个方程、两个未知量。恢复系数正是把"碰撞的弹性程度"这一可测量引入，使方程封闭。这体现了中学物理处理碰撞问题的通用范式：动量守恒 + 能量或恢复系数。
特例 a 弹性碰撞（e = 1）：v1′ = [(m1 − m2)v1] / (m1 + m2)， v2′ = 2m1v1 / (m1 + m2)（v20 = 0 时） → 动能守恒
特例 b 完全非弹性（e = 0）：v′ = (m1v1 + m2v2) / (m1 + m2) → 动能损失最大 ΔEkmax = ½ · (m1m2/(m1+m2)) · (v1 − v2)² = ½μ(v1−v2)²
不变量 质心速度恒定：vc = (m1v1 + m2v2)/(m1+m2) = 常量
动量守恒的等价表述：系统的质心做匀速直线运动
关键判据 冲量分析：碰撞历时 Δt碰 ≈ 10⁻² s，外力冲量 I外 = fΔt碰 ≈ 0。 内力冲量 I内 = Δp 量级为 10⁻¹ ~ 10⁰ kg·m/s。 → 碰撞时间极短使外力冲量可忽略，动量守恒成立。这解释了为什么在有摩擦的斜面小车碰撞实验中难以守恒，而气垫导轨可以。

★ 为什么必须用双门法：计时分辨率误差对比

光电门计时器分辨率约 0.5 ms。遮光片宽 d = 10 mm、v = 0.8 m/s 时，单门法挡光仅 12.5 ms，相对计时误差高达 4.0%；双门法 Δx = 0.12 m 时 Δt ≈ 150 ms（误差 0.33%），Δx = 0.15 m 时 Δt ≈ 190 ms（误差 0.26%）——相差一个数量级。这是"能用双门法就别用单门法"的决定性理由。

改进对比：残余摩擦对守恒精度的影响

不做外推修正时，摩擦越大守恒误差越大（μ=0.02 时达 28%，结论不可靠）；做匀减速外推修正后，μ 从 0 到 0.02 误差始终 < 0.001%。橙色为未修正，绿色为已修正。

实验流程（可直接照做）

  1. 器材准备　气垫导轨（含气泵、调高旋钮、挡光片）、两光电门数字计时器、光电门支架 2 只、滑块 2 个（带配重）、电子天平、游标卡尺。检查导轨是否水平、气泵压力是否充足。
  2. 调节气垫　打开气泵，将滑块静置在导轨中央，轻推一下观察：滑块应做近似匀速运动；往复一段距离后位移基本不变。反复调节导轨底部三只支脚，直到满足上述条件。
  3. 安装光电门　装四只光电门：两只置于碰撞区之前（G₁、G₂）用于测碰撞前速度，两只置于碰撞区之后（G₃、G₄）用于测碰撞后速度。记录每对门间距 Δx（本仿真 0.12 m，实验室建议 20 ~ 40 cm）。若只有两只门，则只能得到碰撞后速度，碰撞前速度须另想办法（如用等效替代法），这是两门简化方案的局限。
  4. 测量质量与几何量　用天平分别测出 m1、m2（含全部配重）；用游标卡尺测遮光片宽度 d，重复三次取平均；读出并记录两对门间距 Δx。
  5. 标定与试撞　轻推滑块 1 撞击静止的滑块 2，观察是否正面碰撞、滑块有无偏转；调整滑块初始位置使碰撞发生在两对光电门之间，且碰撞前后各滑块都能顺利通过两道门。
  6. 正式测量（多次）　改变滑块 1 的初始速度（每次略有不同），重复至少 6 次。记录每个滑块过每道门的挡光时间。
  7. 数据处理（三步法）
    ① 算平均速度：双门法 v̄ = Δx/Δt。Δt 取相邻两门遮光片中心过门时刻之差，即 t中 = (t出+t入)/2。
    ② 作外推修正：双门法给的是两门之间的平均速度，而守恒式要的是碰撞瞬间速度。若导轨有残余摩擦减速（a = μg），按 v(t碰撞) = v̄ + μg(t中 − t碰撞) 修正。此步不可省略——本仿真验证：不做修正时摩擦引起 15% 偏差，做修正后误差 0.001%。
    ③ 算动量并比较：p前 = m1v1 + m2v2，p后 = m1v1′ + m2v2′，求相对误差，对多组数据求平均值。
  8. 误差评估与结论　若平均相对误差 < 3%，在实验误差范围内认为在误差允许范围内，系统动量守恒成立。切勿写"动量守恒成立"为绝对结论——实验只能支持"在误差范围内"。
