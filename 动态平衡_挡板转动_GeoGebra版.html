解析与结论

球受三力平衡：重力 G = mg，挡板弹力 N₁（⊥挡板），斜面弹力 N₂（⊥斜面）。

N₁ = mg · sin α / sin(β − α)
N₂ = mg · sin β / sin(β − α)

• N₂ 单调减小：β 从 α⁺ 到 180°，N₂ 从 +∞ → 0

• N₁ 先减后增：β = 120° 时最小 = 0.5 mg

• α = 30° 固定

GeoGebra 版 vs HTML 版

GeoGebra 优势：

• 原生几何引擎，矢量精确

• 可自由拖拽、缩放、平移

• 滑块原生交互，体验流畅

• 可导出为 .ggb 文件在 GeoGebra 软件中编辑

HTML 版优势：

• 离线可用，无需联网

• 三视图（场景+图解+曲线）同屏

• 可定制性强，配色布局可控
