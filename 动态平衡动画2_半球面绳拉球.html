解析与结论

球受三力平衡：重力 G = mg（竖直向下），半球面支持力 N（沿半径向外），绳拉力 F（水平）。

N · cos θ = mg  ⇒  N = mg / cos θ   |   N · sin θ = F  ⇒  F = mg · tan θ
  • N 单调增大：θ 从 0° 增到 90°，N 从 mg 增大到 +∞
  • F 单调增大：θ 从 0° 增到 90°，F 从 0 增大到 +∞
  • 解析法要点：建立直角坐标系，用正交分解列出平衡方程，直接求解 N、F 与 θ 的函数关系
  • 与动画一对比：图解法适合判断"先增后减"等极值问题，解析法适合精确求函数关系
