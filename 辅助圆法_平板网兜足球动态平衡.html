辅助圆法 · 平板OA转动中的足球动态平衡

轻绳与板夹角 θ = 30° 恒定，板 OA 由水平缓慢逆时针转至竖直。力矢量仅以颜色与长度表达大小。
重力 G = 12 N（恒定·竖直向下）
板对球弹力 FN（⊥OA，随板转）
绳对球拉力 FT（沿绳指向 A）
辅助圆（弦=重力 G，圆周角 60°）

① 物理情景（球随板转动，θ 恒定）

② 力矢量三角形 + 辅助圆

③ FN 与 FT 随 α 的变化（α：板与水平夹角）

板转角 α：0° FN=12.00 N FT=0.00 N 两力夹角=120°（恒定）
选项判定（答案：A、D）
A 正确FN 最小值为 4√3 N（≈6.93 N），出现在板竖直（α=90°）时。
B 错误α=30° 时 FN=8√3 N、FT=4√3 N，二者并不相等；FN=FT 发生在 α=60°（均为 12 N）。
C 错误FN=2FT 可以取到，恰好在 α=30°（8√3 = 2×4√3）。
D 正确FT 最大值为 8√3 N（≈13.86 N），出现在板竖直（α=90°）时。
模型抽象与辅助圆法推导

1. 受力模型（球）：球受三力处于动态平衡——重力 G（12 N，竖直向下，恒定）；板对球的弹力 FN（始终垂直于板 OA）；绳对球的拉力 FT（沿绳指向 A，与板夹角恒为 θ=30°）。

2. 核心不变量：板转动时 FN 与 FT 的方向都随时间旋转，但二者夹角恒为 90°+θ = 120° 不变。这正是"一恒两转、夹角不变"型动态平衡。

3. 辅助圆：把三力首尾相接成矢量三角形。重力 G 是固定边（弦），顶点（FN 与 FT 的交点）对弦 G 所张的角 = 180°−120° = 60°（恒定）。因此该顶点轨迹是一段圆弧——以 G 为弦、圆周角 60° 的辅助圆。圆半径为 R = G/(2·sin60°) = 12/√3 = 4√3 N。

4. 解析关系（取沿板、垂直板分解）： 沿板方向 FTcosθ = G·sinα ⟹ FT = G·sinα/cosθ； 垂直板方向 FN = G·cosα + FTsinθ ⟹ FN = G·cos(α−θ)/cosθ。 代入 θ=30°、G=12 N 得：FT = 12·sinα/(√3/2)，FN = 12·cos(α−30°)/(√3/2)。

5. 关键点：α=30° 时绳恰好水平，FN=8√3（最大）、FT=4√3（=FN/2）；α=60° 时 FN=FT=12 N；α=90° 时 FN=4√3（最小）、FT=8√3（最大）。据此判定 A、D 正确，B、C 错误。

注：α=0° 时 FT=0（绳恰拉直而无张力），球仅靠板支撑；随板转动绳张力逐渐增大，几何上球被绳"锁"在板上使 θ 保持 30°。
